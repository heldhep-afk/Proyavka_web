# Проявка — фото и печать онлайн

Учебный прототип веб-приложения для организации в сфере фотоуслуг и копировально-полиграфического обслуживания населения. Выполнен в рамках практики (НГУЭУ, дисциплина «Оптимизация веб-приложений»).

Пользователь загружает снимок, применяет эффекты, «примеряет» типовые образы, собирает макет под формат печати и отправляет заказ.

## Возможности

- **Личный кабинет:** регистрация и вход, история заказов, библиотека собственных эффектов.
- **Эффекты:** оригинал, чёрно-белое, сепия, тёплое, холодное, контраст, плёнка, виньетка; загрузка своего PNG-эффекта (рамка, текстура).
- **Примерка образов:** образы «Деловой», «Пляж», «Праздник», «Новый год» и отдельные наклейки, которые перетаскиваются по макету.
- **Макет и заказ:** форматы 10×15, 13×18, 15×21, A4 и 3×4, рамки, ориентация, тип бумаги, количество копий, расчёт стоимости, отправка заказа, скачивание макета в JPG.
- **Адаптивность:** смартфон и компьютер, светлая и тёмная темы, безопасные зоны экрана, управление с клавиатуры.

## Стек

HTML5, CSS3 (переменные, Grid, Flexbox), JavaScript без библиотек и сборки; разметка, стили и скрипт лежат в отдельных файлах. Canvas API (эффекты считаются попиксельно), Pointer Events, Web Storage, Web Crypto (SHA-256). Шрифты Unbounded и Onest подключаются с Google Fonts, есть запасные гарнитуры.

## Запуск

Сборка не нужна. Откройте `index.html` в браузере или запустите локальный сервер (файлы `css/style.css` и `js/app.js` подключаются автоматически):

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

### Публикация на GitHub Pages

В репозитории есть workflow `.github/workflows/pages.yml`. После загрузки кода откройте Settings → Pages и в разделе Source выберите **GitHub Actions**. Сайт появится по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Ограничения прототипа

- Данные пользователей, эффекты и заказы хранятся в `localStorage` браузера. Заказ фактически не передаётся в салон, а вход возможен только на том устройстве, где выполнена регистрация.
- Пароль хранится как хэш SHA-256 без соли. Для рабочей системы нужны серверная часть, база данных и хранение паролей через bcrypt или Argon2, а также соблюдение 152-ФЗ.
- Фотографии обрабатываются только в браузере и никуда не отправляются.

## Развитие

Серверный API и база данных, интеграция с учётной системой салона, онлайн-оплата, загрузка снимков из облачных хранилищ, расширение услуг копирования и печати документов.
